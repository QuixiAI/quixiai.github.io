Memory, identity, and the shape of becoming.

Hexis is a Postgres-native cognitive architecture that wraps an AI model with persistent memory, beliefs, identity, goals, and autonomous behavior. You run it on your own computer, and you control its data and integrations.

Hexis at a glance

  • Runs locally as open-source software
  • Uses PostgreSQL as the system of record
  • Supports multiple AI model providers
  • Stores persistent memory and identity
  • Connects to external services only when configured
What it does

A cognitive layer around the model you choose.

Hexis provides continuity across sessions rather than treating every conversation as a blank slate.

Persistent memory

Episodic, semantic, procedural, strategic, and working memory live in PostgreSQL alongside their supporting evidence.

Identity and goals

Values, beliefs, boundaries, emotional state, goals, and an autonomous heartbeat can persist over time.

Auditable behavior

Memory changes and belief revisions can be traced, and unsupported action claims are visibly corrected.

Google user data

How Hexis uses Gmail access

Gmail is an optional integration. Hexis requests access only after the user deliberately chooses to connect a Google account and approves the permissions shown by Google.

Purpose of access

Depending on the capabilities enabled by the user, Hexis may use Gmail permissions to search and read messages, send messages, and organize mail with actions such as labeling, archiving, or moving messages to trash.

Hexis does not receive Gmail access merely because it is installed. Google issues authorization only after the user signs in and grants consent.

Data handling

  • User control: the user chooses whether to connect Gmail and may revoke access through Hexis or their Google Account.
  • Local-first operation: credentials and application state are intended to be stored by the user's own Hexis installation, not in the public source repository.
  • No advertising use: Google user data is not used for advertising or sold to third parties.
  • Configured processors: content the user asks Hexis to analyze may be sent to the AI provider or other service the user has configured. Those services have their own terms and privacy practices.
  • Least privilege: Hexis should request only the permissions required for the Gmail features the user enables.
For the complete disclosure of how Google user data is accessed, used, stored, shared, retained, and deleted, read the Hexis Privacy Policy.
