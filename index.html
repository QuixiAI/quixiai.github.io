L3 · Serving

SlimServe runs frontier models on cards you can buy used.

SlimServe is a simplicity-first inference engine for a curated set of open models: GLM-5.2-Vision, Kimi K3, DeepSeek-V4-Flash, and Qwen3.8. It takes ds4's interface philosophy, is built on vLLM, and uses every performance trick I can land.

Every configuration it will run is a measured profile. It refuses anything else, so you never find out eight hours into a 244 GiB download that the combination doesn't fit.

L2 · Kernels

QuixiCore: native kernels for every accelerator in the room.

QuixiCore is one kernel contract with six standalone implementations. CUDA kernels are written like CUDA kernels, Metal kernels like Metal kernels, and so on down the line. The backends share the same operations, quant formats, correctness tests, and benchmark method, but no source code.

It covers the operations inference actually spends its time in: quantized GEMM and GEMV, MoE routing and grouped GEMM, paged and MLA attention, speculative decode, and Mamba/SSD. SlimServe's throughput rests on it.

L4 · Mind

Hexis: memory, identity, and the shape of becoming.

Today's LLMs are smart enough. What they lack is continuity. Hexis wraps any model with a mind that lives inside PostgreSQL: layered memory, beliefs that can say why they changed, drives, an energy budget, and an autonomous heartbeat that keeps pursuing goals while you're away.

It runs locally and your data stays yours. The whole mind exports to a single file you can inspect. The agent consents before it operates, and it is allowed to refuse.

Language

With: a systems language that doesn't fight you.

With compiles to native code through LLVM, with no interpreter and no GC pauses. Ownership-based memory safety rules out use-after-free, double-free, and data races, and you never write a lifetime annotation.

It uses indentation for scope, type inference, f-strings, first-class regex, let … else, scoped with blocks, and direct C interop. The compiler is self-hosting, with CI on Linux, macOS, and Windows for both x86_64 and arm64.
